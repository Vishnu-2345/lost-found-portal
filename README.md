# Lost & Found Portal – DBMS Mini Project

This project is a Lost & Found Management System built for the DBMS Mini Project.

##📁 Files Included
- **app.py** – Python frontend/CLI for interacting with the database
- **lost_found_portal.sql** – Complete SQL script containing:
  - Table creation (DDL)
  - Insert queries (DML)
  - Triggers
  - Stored Procedures
  - Functions
  - Join / Nested / Aggregate queries

## 🛠 Technologies Used
- MySQL
- Python (Streamlit/CLI)
- GitHub

## 📝 How to Run
1. Import `lost_found_portal.sql` into MySQL Workbench
2. Run `app.py` to access the interface
